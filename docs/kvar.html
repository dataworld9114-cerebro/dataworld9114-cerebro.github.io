데이터 연계 원리

BioProject와 BioSample은 시스템 등록(UI)에서 매핑됩니다. 단, KVar는 엑셀 내부에 accession을 직접 기재하는 방식을 함께 사용합니다.

1. BioProject 웹 등록
시스템이 KAP# 발급 · umbrella 불가
↓
2. BioSample 엑셀 작성
(패키지별 샘플 속성만 작성)
※ 엑셀 내 BP ID 입력란 없음
↓
3. 시스템(웹) 연계
엑셀 업로드 시 화면 UI에서
[상위 BioProject ID] 선택 → KAS# 발급
※ 유전체 변이(KVar) 연계

샘플 단위 정밀 매핑을 위해
KVar 엑셀 Part 3 내부의
[BioSample accession ID] 필드에
KAS#를 직접 기재합니다.
(신규 등록 시엔 Sample name — 그룹 택1)
4. VCF 파일 내부에도 ID 재기재

SNP: ##batch=(Experiment ID)
##population_id=(SampleSet ID)
SV: INFO의 EXPERIMENT= · SAMPLESET=
공통: ##bioproject_id= · ##biosample_id=
메타데이터와 문자 그대로 일치 필수
