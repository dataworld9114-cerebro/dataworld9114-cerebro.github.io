유전체(Genome) 데이터 등록 인터랙티브 가이드 — 염기서열(Nucleotide sequence)

데이터 연계 원리

KNA(Korea Nucleotide sequence Archive) 공식 가이드(kobic.gitbook.io/kna-documentation) 기준 연계 방식입니다.

1. BioProject 웹 등록
시스템이 고유 ID 발급
↓
2. BioSample 등록
Nucleotide/Genome은 1개,
MAG/TLS/TSA는 복수 선택 가능
↓
3. 염기서열(KNA) 등록 - Project & Sample 단계
화면 UI에서 BioProject 선택 →
BioSample(들) 선택 → 공개일자 지정
※ KRA(원시데이터) 연계

어셈블리에 사용한 원시데이터가 KRA/NCBI SRA에 있다면,
Assemble 단계의
[Reference KRA Data] 항목에
Run ID를 직접 기재하여 연계합니다.
※ 공식 KNA 제출 9단계 (Organism 기준)
1) Project & Sample
2) File Upload
3) Affiliation
4) Reference
5) Assemble
6) Nucleotide (Genome·Nucleotide 전용)
7) Mapping (MAG 전용)
8) Protocol
9) Review & Submit
