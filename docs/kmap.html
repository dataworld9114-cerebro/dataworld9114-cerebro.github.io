데이터 연계 원리

BioProject와 BioSample은 엑셀 내부가 아닌 시스템 등록(UI)에서 매핑됩니다.

1. BioProject 웹 등록
시스템이 고유 ID 발급
↓
2. BioSample 등록
sampleName 발급/확정
↓
3. KMAP 대사체 등록
BioProject·BioSample 선택 후
KMAP_metadata.xlsx 업로드
※ 대사체(KMAP) 연계

파트 12 양적 정보 파일의 sampleName은 BioSample의 sampleName과 완전히 같아야 합니다.

MS는 Feature ID, NMR은 Common name으로 파트 13과 연결됩니다.
