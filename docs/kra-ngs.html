NGS 유전체 데이터 등록 인터랙티브 가이드 (K-BDS KRA Full)

NGS 데이터 연계 원리

K-BDS KRA(Korea Sequence Read Archive) 등록은 연구과제(BP)부터 원시 시퀀싱 파일(Run)까지 유기적으로 연계됩니다.

1. BioProject 웹 등록
프로젝트 단위 고유 Accession 발급
↓
2. BioSample 엑셀 등록
시료 특성(Standard 9종 / MIMS 23종)
웹 UI에서 상위 BioProject 연결
↓
3. NGS 실험(Experiment) 작성
기법, 플랫폼, 라이브러리 프로토콜
BioSample과 1:1 또는 1:N 매핑
↓
4. Run & Analysis 파일 업로드
FASTQ, BAM 등 대용량 데이터 전송
MD5 Checksum 무결성 검증 필수
※ 타 유전체 데이터와의 관계
• 기능유전체(5장): 가공 매트릭스 등록 시 KRA Experiment ID 참조
• 조립 서열(6장): Genome/MAG 제출 시 원시 KRA Run ID 참조
• 유전체 변이(7장): VCF 변이 데이터의 모체가 되는 시퀀싱 연계
